# Glossary - Modernization Control Plane

**Last updated:** 2026-09-29

This is the shared dictionary for the Modernization Control Plane. It sets one agreed word for each thing in the product, so the spec, the requirements, and the team never mean different things by the same word - or the same thing by different words. Use it to look up what a term means, what it belongs to, where it comes from, and, when the word was contested, why that word was chosen.
